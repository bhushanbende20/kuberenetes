Connect Langdock to this Local Qwen Instance

Langdock connects to custom models using an OpenAI-compatible REST API. This application provides the exact POST /chat/completions endpoint Langdock requires.

1. Langdock Workspace Settings

  1. Log in to your Langdock workspace.
  2. Go to Settings → Models (or Custom Models / BYOK).
  3. Click "Add Custom Model" or "Add Provider (OpenAI Compatible)".
  4. Fill in the parameters shown on the right panel.
  5. Save and select qwen3.5:4b in any Langdock Chat or Agent!
💡 Tip for Remote/Cloud Langdock: If Langdock runs in the cloud (app.langdock.com), expose your local port with a tunnel like ngrok http 8000 or deploy to your Kubernetes cluster and use an Ingress URL.

Available API Endpoints

            
You can query this bridge service using any standard client (Python, cURL, Langdock, LangChain, or Node.js).

            
            

              

                POST
                /chat/completions
                Langdock & OpenAI standard endpoint (Supports SSE streaming)
              

              
curl -N http://localhost:8000/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.5:4b",
    "messages": [{"role": "user", "content": "Explain Kubernetes in one sentence"}],
    "stream": true
  }'

            


            

              

                POST
                /api/chat
                Direct Ollama Native Proxy
              

              
curl -N http://localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.5:4b",
    "messages": [{"role": "user", "content": "Hello Qwen!"}],
    "stream": true
  }'
